# 项目文件与最小模型调用页面

从首页项目卡的“文件与素材”进入 `/projects/:projectId/files`。复用统一 API 客户端和项目上下文，显示 MinIO 媒体元数据，提供上传、受控预览和下载；图片预览最多 16 MiB，其他文件仅读取一字节确认权限后提示下载。上传上限与后端一致为 512 MiB，不自动重试。

当前生成表单仅使用已接通且获批的 qwenImage21Text，明确提交 1K、1:1，不改变原节点保存的 2K 或其他规格。生成名额、幂等、取消及结果归属由服务端控制，前端显示限制不能替代授权。切换项目/账号和离开页面会中止读取及清理 Blob URL；浏览器断线不表示后端生成停止。

这不是原工作区编辑器或完整素材管理迁移：原文档写入/修订冲突、其他规格与模型、Agent/FFmpeg 按 M3 批次继续。
