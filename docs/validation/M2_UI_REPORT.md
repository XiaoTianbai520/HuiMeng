## 交付结果

- 修复登录后 `/preferences` 尚未实现导致页面加载失败的缺口。偏好按会话账号隔离，拒绝嵌入共享密钥/令牌/供应商配置，并限制大小与深度；没有增加数据库迁移。
- 新增管理员安全模型目录 `GET /api/v1/admin/models`，可读取未批准模型并使用已有批准接口。成员仍只看到已批准模型。OpenAPI 当前 **39 操作、33 路径、26 已实现操作**；原 M1 的 38 操作保持兼容，新增 1 个只读管理操作。
- 新增 `/team`：账号创建/开停/角色/密码重置、项目创建/改名/归档/成员、供应商/市场 Key、模型批准和外部凭证。项目名称通过服务端 PATCH 保存；首页增加真实退出和管理员入口。旧模型设置入口转向团队管理，不使用旧 settings 整包写共享配置。
- 密码、Key 在提交结束和卸载后清空；外部凭证在关闭、离开或签发期间页面变化后不重新展示。所有分页继续加载到 nextCursor=null，并拒绝重复游标和账号切换后的旧结果。
- 登录后不再挂载尚未开放的 FFmpeg 事件订阅；组件仍保留待 M3 接入，没有为消除前端错误而放开路由。服务器权限依旧默认拒绝，127 条源路由全部 publicEnabled=false。
