# M3-03 项目级名额与媒体生成验收

> 2026-10-26。范围：现用 Qwen 2.1 的两个图片模型（`qwenImage21Text` 文生图、`qwenImage21Edit` 单图指令编辑）、完整规格、原子五名额、幂等、真实取消与结果归属。仅使用合成账号、夹具项目和隔离执行器；真实生成使用工作机手动启动的 ComfyUI，仓库不含团队凭据。

## 1. 结论

| 项 | 结果 |
| --- | --- |
| 两模型与 8 种画幅、3 档像素预算 | 通过：省略 `size`/`ratio` 时服务端按 1K、1:1 提交，合法显式规格（含 2K）保留，响应 `data[].spec` 回显实际宽度高度 |
| 原子五名额 | 通过：同项目 5 个占位成功，第 6 个 429 `PROJECT_CAPACITY_EXCEEDED`，且执行器 `/prompt` 计数未增加 |
| 幂等 | 通过：同键重放返回 202 与原运行 ID，未重复提交执行器；同键不同请求 409 `IDEMPOTENCY_CONFLICT` |
| 取消 | 通过：取消经队列定向接口确认后运行转 `CANCELLED` 且名额释放，取消不产生重新提交 |
| 结果归属 | 通过：生成件写入本项目媒体，`.huimeng-media/<id>.png` 可读；撤权后不落结果（沿用 M2 回归） |
| M0-I15 默认规格 | 复验通过：默认值固定在服务端并回显，页面不再把 2K 静默改成 1K，也不把 1K 静默改成 2K |
| 视频生成 | 未纳入本批：H3 五个模式的图模板与参数属 M3-05，本轮不声称视频可用 |
| 音频 | 按业务确认只保留路由/配置/权限，不执行独立音频成功流 |

## 2. 实现要点

- **规格计算与供应商 1.0.0 一致**：`0.5MP=736`、`1K=1024`、`2K=2048` 的像素预算，宽高按 `sqrt(w/h)` 换算后 32 对齐，写入 `EmptyLatentImage` 并与编码节点的 `resolution` 同步；算法集中在 `ComfyImageClient.resolve`，未知尺寸或比例直接 400，不做静默降级。
- **单图编辑**：参考图只接受项目内虚拟路径 `.huimeng-media/<uuid>.png` 且 `mimeType` 必须为 `image/png`；占位前先校验归属与 16 MiB 上限，越权返回 404、格式不符 400。执行时把 PNG 以 `/upload/image` 送入执行器，文件名由服务端运行 ID 生成，浏览器无法指定路径。
- **执行器任务 ID**：改为使用 ComfyUI 返回的实际 `prompt_id` 查询、取消与补偿核对；提交前先写入本运行 ID 作为临时参照，提交失败进入 `LOST` 时仍可对账。
- **名额先于执行器**：数据库事务完成占位后才探测执行器就绪，探测失败立即释放；因此第 6 个请求连 `/system_stats` 都不会触发。
- **镜像内固定模板**：新增 `qwen-edit.json` 图生图模板，与 `qwen-text.json` 一样逐字段固定在仓库，不接受浏览器工作流或模型文件。
