日期：2026-10-25。接续已推送的 `28c87c7`。本批完成 M3-W02；M3-W03 已接独立文档编辑区域，但原文件树、文档面板和画布修订链尚未迁移，M3-01 整体仍进行中。没有升级正式 API/Web/Bun，没有访问真实 MySQL、MinIO 或模型。

## 实现与契约

沿用 Spring Controller → Service/impl → 受控 I/O 分层，增加以下精确入口，前缀为 `/api/v1/projects/{projectId}/creative/workspaces/files/`：

| 方法与后缀 | 行为 |
| --- | --- |
| GET `list?path=` | 项目内相对目录；空 path 为项目根，返回 directory=项目 ID、entries 和 empty，不返回物理路径 |
| POST `mkdir` | `{path}`，只建一层，父目录须存在；已存在返回 409 |
| POST `copy` | `{path,target}`，同项目复制文件或目录，不覆盖目标 |
| POST `rename` | `{path,target}`，同项目移动/重命名，不覆盖目标 |
| DELETE `remove` | `{path,recursive?}`，非空目录默认拒绝，只有显式 recursive=true 才递归 |

写操作要求同源、会话 CSRF、有效项目成员和活动项目；管理员也须加入项目。拒绝未知/重复查询参数、客户端 directory、路径逃逸、链接、特殊文件和 `.huimeng-*` 受控命名空间；不能删除项目根。列表隐藏链接、受控项和不兼容名称，最多扫描 5000 条，目录在前。复制限制 512 MiB、10000 项及 64 层；删除先做数量/深度与链接检查。达到上限明确拒绝，没有隐式分页或后台任务队列。

文件保存及本批所有变更共用单 Spring 进程的项目条带锁，防止目录移动/删除与保存相互绕过。读写以 SecureDirectoryStream 逐层无链接打开；JDK 缺少的 mkdirat/renameat2 由固定 JNA 5.17.0 调用 Linux x86_64 原语，后者使用 RENAME_NOREPLACE。复制先写同父目录的私有临时项，提交前重查授权，再发布到不存在的目标；失败清理本次精确临时项。各变更记录 ATTEMPT/SUCCESS 审计，不记录文件路径或正文。

JNA 本地库从构建 JAR 提取、记录 SHA-256，并随镜像放在只读应用路径，禁止临时解包/系统同名版本；保留非 root、只读根和 /tmp noexec。部署前准备命令、Apache-2.0 选择及 libffi 文本见[部署说明](../../backend/deploy/README.md)和[许可归档](../../backend/licenses/README.md)。这不构成依赖安全更新或 M4 发布验收。

当前 [OpenAPI](../api/openapi.yaml) 为 **49 操作/42 路径，41 实现**；源映射 13 frozen、87 proposed、25 excluded、2 internal。新冻结 R117/R119/R120/R122/R123；全部 127 条源路由 publicEnabled 仍 false，不开放 Bun 或创作通配代理。

## 实际浏览器体验

现有“文件与素材”页增加“项目文档”区域：目录导航、新建、复制、重命名、删除确认，以及读取快照后的原格式文本手动保存。覆盖携带读取修订号，409 后保留草稿并禁用继续保存，可重新读取或另存为不覆盖原件的副本；关闭/切换文档与离开路由提示未保存修改。项目/账号切换清理读取和草稿，撤权响应清空列表/文档并禁用操作。当前没有自动保存，也没有连接原画布或原文档面板。

真实浏览器连接本机 Vite，经仅回环 SSH 转发进入独立 Linux Spring/H2。完成登录、目录/文档创建、编辑保存后关闭再打开、复制/重命名、目标存在错误、删除确认取消、未保存修改取消、双标签冲突/保留草稿/另存副本、成员撤权清空等 **21 项**，见[浏览器结果](evidence/m3-workspace-browser.json)。两个标签使用同一个合成成员账号；不能作为两名不同用户或原画布验收。浏览器只确认删除表单与取消，没有点击最终删除；真实递归/文件删除由下述 HTTP 测试覆盖。未测试移动视口。

实际操作发现并修正副本名称把后缀放在扩展名之后的问题，以及撤权后空状态仍引导新建的问题。最终浏览器控制台检查无警告/错误；随后主动触发的撤权 403 属预期拒绝。
