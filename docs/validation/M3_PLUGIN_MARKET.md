# M3-08 插件市场与团队插件管理

> 2026-10-26。范围：已安装能力登记（节点/工具/技能/扩展/Agent）、市场代理（搜索、收藏、安装）、配置与秘密字段、启停、导出、允许的卸载、技能与 Agent 文档编辑、团队说明文档。使用合成账号、临时 H2 与本地合成市场上游；未连接真实市场凭据，也未执行任何插件代码。

| 项 | 结果 |

| 启停与卸载 | 通过：启停即时生效；内置能力（`source=builtin`）拒绝卸载，其余可卸载并清理文档 |
| 导出 | 通过：节点/工具/扩展导出原始内容；技能/Agent 打包 zip |

## 2. 实现要点

- **登记表**（`V7__plugin_registry.sql`）：`plugins`（类型+标识唯一、摘要、来源、启停、配置、原始内容）、`plugin_documents`（文档型能力的文本文件）、`market_collections`、`app_documents`（团队说明与 A2A 设置）。
- **安装校验顺序**：文件大小/文件名 → 类型 → 解析（文本或归档，先判越界与体积）→ 摘要 → 与已装版本比对 → 落库/替换 → 审计。任一步失败都不改动已装版本。
- **市场代理**：`PluginServiceImpl.search` 用 `SecretBox` 解密团队市场凭据后转发请求，10 秒超时，非 200 一律按 503 处理；响应同时回填本地收藏状态。
- **下载来源**：`huimeng.market.artifact-hosts` 允许清单 + 回环例外；`https` 强制；不跟随重定向（`Redirect.NEVER`），避免跳到清单外主机。
- **秘密字段**：字段名匹配 `key|secret|token|password|credential` 时用 `AES-GCM`（AAD 绑定 `plugin:<id>:<field>`）加密；读取时统一 `***`，导出与列表都不含明文。
- **前端契约**：`route-map.json` 增补 5 条平台白名单（市场搜索/收藏/安装、已安装列表、`capabilities/ext/read`），页面只经既有 axios 客户端访问。

## 4. 未覆盖

- **插件运行期加载**：节点/工具/扩展安装后没有执行器加载它们，Agent 也尚未从市场工具中取函数；A12 的"Agent 实际加载工具"仍不成立。
- **真实市场**：只用合成上游验证协议、鉴权头与摘要；团队真实 TF-Router 凭据未在本轮调用，市场目录的版本/摘要语义仍按 M0-06 结论处理。
- **自定义媒体供应商文件**：`providers/media/*` 只提供空列表与显式拒绝，供应商代码审查与执行隔离未做。
- **技能/Agent 内容生效**：文档可编辑保存，但技能注入提示词、Agent 包运行的链路未接。
- **卸载时的运行占用**：当前只按来源判定，未检查是否有正在运行的任务占用该能力。
