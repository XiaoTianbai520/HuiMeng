## 2. 最小依赖的实际边界

- 首页增加“文件与素材”，只使用统一 Spring 客户端。媒体列表、上传、受控预览、下载及生成结果归属均按项目逐次授权；前端按钮限制不是权限实现。
- 生成入口沿用冻结的 JSON 空白保活/业务终态协议及 X-Run-Id。项目行锁原子抢占五名额，幂等绑定项目、发起人、操作和请求摘要；同键不同内容 409，重复键返回原运行 202，不重新调用供应商。运行查询/取消仅发起人可用，项目成员身份仍须有效。
- ComfyUI 使用固定现用 Qwen 2.1 图，仅注入提示词、随机种子及服务端项目/运行前缀。不接受浏览器指定工作流、端点、模型文件或绝对目录。仅连接用户手动启动的 ComfyUI，没有启动、重启、更新节点或下载权重。
- 使用 ComfyUI 0.37.0 的 `/api/jobs/{id}/cancel` 原子定向取消接口，不发全局中断；取消确认前保留名额。连接失败或重启导致执行状态未知时标 LOST 并保留名额，只有查到终态后释放，不伪造成功。真实 ComfyUI 取消、跨入口容量和重启全场景仍在 M3/M4；本批取消已做协议/服务及真实 MySQL 名额验证。
- 结果通过私有 MinIO 保存；`.huimeng-media/{mediaId}.png` 是受控项目虚拟相对路径，精确文件 read 重新授权后映射对象；它不是物理目录或对象键。原文档仍使用安全目录句柄，Windows 原文档 read 的 503 限制未整体消除。
- 文件页面不启动尚未迁移的 MCP 控制连接；控制连接只在实际工作区和控制器就绪时开启，避免无关的持续 403 重连。

## 3. 修复与失败证据

真实探测先后发现两项问题：接入固定图时误改 VAE 别名，解码失败；恢复原 2.1 VAE 后出图成功，但 Windows 返回反斜杠子目录被严格定位校验拒绝。现已恢复原模板，并在精确项目/任务边界内规范化分隔符。两次失败均为 FAILED 且名额释放，没有误报完成，见[失败回归记录](evidence/m2-real-failure-regressions.json)。固定图逐字段比较与 Windows 输出路径负例加入默认回归。

浏览器夹具首次达到原 30 分钟时限后退出；后续上传没有成功，未计作通过。最终夹具改为最多两小时并在任务结束主动停止，重新执行页面上传、生成与权限检查；最终证据记录的上传与生成都来自同一新夹具。
