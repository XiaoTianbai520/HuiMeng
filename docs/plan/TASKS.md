# 绘梦 1.0 实施任务（TASKS）

> 状态：M0、M1 已完成；M2 安全基座已实现并完成真实 MySQL/HTTPS API 验证，部分验收保持待办，见[M2 报告](../validation/M2_REPORT.md)。M3–M4 未开始。以现行 PRD、DESIGN、CONTRACTS 为基线，不将基础安全测试通过等同 1.0 业务验收。

## 1. 任务管理规则

状态统一使用“未开始 / 进行中 / 待验收 / 完成 / 阻塞”；只有完成标准有证据（提交、测试报告、录制样例或演练记录）才能标为完成。所有任务应关联 PRD 的 FR 编号和[迁移清单](../product/TOONFLOW_WEB_MIGRATION.md#6-一期验收矩阵)的 A01–A18。每批创作路由按逐路由台账推进；未入白名单、未做权限和契约测试的接口不得在局域网开放。

任务顺序以依赖为准，不把阶段名等同日历排期。M0、M1 是共同基线；M2 安全入口先于 M3 对外开放；M4 在完整功能回归后上线。
