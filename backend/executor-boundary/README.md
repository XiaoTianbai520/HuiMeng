# Bun 内部身份边界

M2 的独立健康检查接收器，不是创作执行器迁移成果。没有上游 router、供应商、插件、MCP/A2A 分派或通配代理。固定执行环境 Bun 1.3.14，零第三方依赖。

在本目录执行 `bun test`（本机 Bun 1.4.2 亦作检查；部署按 1.3.14 重验）。`bun run server.ts` 需挂载 `HM_INTERNAL_KEY_FILE`（32 字节随机数的 Base64）和 `HM_WORKSPACE_ROOT`。默认只监听回环，容器内可监听专用网络，无宿主机端口映射。

Spring 签发 HMAC-SHA256 请求上下文，包含项目/用户/工作区键、请求 ID、方法、路径、正文摘要、20 秒有效期及一次性 nonce。接收器验证签名、有效期、重放、工作区键和目录后才响应 `/internal/ready`；旧全局凭证及客户端 directory 不获信任。M3 按路由批次迁移执行逻辑，必须继续使用相同验证入口，不能给此接收器挂通配代理。
